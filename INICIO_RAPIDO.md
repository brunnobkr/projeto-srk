# 🚀 Início Rápido - App ITCC

## Passo 1: Instalar Dependências

```bash
npm install
```

## Passo 2: Rodar o App

```bash
npm run dev
```

O app estará disponível em: **http://localhost:5173**

## Passo 3: Instalar como App (PWA)

### No Computador:
1. Abra `http://localhost:5173` no Chrome ou Edge
2. Procure o ícone de instalação na barra de endereços
3. Clique em "Instalar"

### No Celular:
1. Acesse o IP do seu computador na rede (ex: `http://192.168.1.100:5173`)
2. No Chrome (Android) ou Safari (iPhone):
   - Menu → "Adicionar à tela inicial"
3. O app aparecerá na sua tela inicial!

## Passo 4: Build de Produção (Opcional)

Para criar uma versão otimizada:

```bash
npm run build
npm run preview
```

## 📱 Compartilhar na Rede

1. Encontre seu IP:
   ```bash
   ipconfig  # Windows
   ```

2. Inicie o servidor:
   ```bash
   npm run dev
   ```

3. Compartilhe: `http://SEU_IP:5173`

## ✅ Pronto!

Agora você tem um app instalável funcionando!
